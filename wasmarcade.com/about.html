Real game engines, compiled for the web

WASM Arcade is a library of games whose engines have been compiled to WebAssembly. Not videos, not cloud streams, not a console emulator: the actual engine code of full 3D games, running inside an ordinary browser tab on your own device.

An archive, not a store

Every game here was made by a studio or publisher that owns it. WASM Arcade does not own them and does not sell them. It keeps old games playable, the way a library keeps old books readable, so that the culture around them does not disappear when the hardware and the plugins do. If you own a game here and want it removed, the copyright page says how.

Why we built it

For most of the web's history, "browser game" meant something small. Anything serious needed a download, an installer, a plugin or a particular operating system. WebAssembly changed that. It lets a browser run compiled code at close to native speed, in the same security sandbox as any web page, on any operating system. Paired with WebGL for graphics, Web Audio for sound and browser storage for saves, a browser can now run the same engines that once needed a console or a gaming PC.

WASM Arcade exists to show that with games people already know. When a 2002 open-world game boots in a tab, the question of what the web can do answers itself.

What this brings to the web

  • No install, no plugin. A link is the whole distribution channel. Open it and play.
  • Runs on your hardware. Nothing is streamed from a data center, so there is no queue, no subscription and no video-compression blur. Your own graphics card draws every frame.
  • Safe by design. WebAssembly runs inside the browser's sandbox, with no more access to your computer than any other web page.
  • Code outlives its platform. Flash Player is gone and the PlayStation 2 is long retired, but compiled to WebAssembly these engines run anywhere a modern browser runs. That is how games stay playable instead of just remembered.

How a game runs here

  • Streamed and cached. Game data loads in the background as it is needed and your browser caches it, so only the first visit waits.
  • Your saves stay with you. Progress is stored in your browser's own storage, never on our servers. The Save Manager on each game exports a save to a file and imports it again.
  • No account. We never ask for your name, email or a password to play.
  • Best on desktop. Current Chrome, Edge and Firefox give the best results; the GTA games also have touch controls on phones and tablets.

What we stand for

  • Credit where it is due. The games belong to the studios that made them. The engines and ports belong to the volunteers who built them. We say so at the foot of every page.
  • Respect for rights holders. WASM Arcade is not affiliated with any of the publishers whose games appear here. If you own a game on this site and want it removed, we will remove it; see our copyright and takedown policy.
  • Honest ads. Serving gigabytes of game data costs money, and advertising pays for it. We keep ads away from the game while you play, and our privacy policy names every advertising partner.

Built on open source

This library stands on the work of these projects and their communities:

  • re3 and reVC, open-source reimplementations of the GTA III and Vice City engines.
  • Emscripten, the compiler toolchain that turns C and C++ into WebAssembly.
  • Ruffle, the Flash Player emulator written in Rust and compiled to WebAssembly.
  • EaglercraftX and TeaVM, which bring Minecraft 1.8.8 to the browser from Java.
  • BlueMaxima's Flashpoint and the Internet Archive, for their work keeping Flash games available.

Questions

What is WASM Arcade?

WASM Arcade is a library of real game engines compiled to WebAssembly. It runs Grand Theft Auto: Vice City and Grand Theft Auto III on the open-source reVC and re3 engines, The Simpsons: Hit & Run as a native WebAssembly build, Minecraft 1.8.8 through EaglercraftX, 227 arcade boards — Capcom's CPS1, CPS2 and CPS3, Neo Geo and more — through the EmulatorJS build of FinalBurn Neo, and 878 classic Flash games through the Ruffle emulator, all inside a browser tab. There are no accounts and no in-game purchases.

Can I still play Flash games?

Yes. Browsers removed the Flash plugin, so the Flash Arcade runs each game on Ruffle, an open-source Flash Player emulator written in Rust and compiled to WebAssembly. Most classic games run well; a few that rely on features Ruffle has not implemented yet can behave oddly.

What do I need to play?

A modern browser with WebAssembly and WebGL 2.0 support, such as Chrome, Edge, Firefox or Safari 15.4 and later. Nothing else is required. Games load as you play and your browser caches them for next time.

Which browsers work best for GTA Vice City and GTA III?

Current Chrome, Edge and Firefox on a desktop or laptop give the best results, with a keyboard and mouse or a gamepad. The Simpsons: Hit & Run is a threaded engine, so it needs a browser running in an isolated context.

Where are my save games stored?

Your progress is written to local browser storage on your own device, so saves persist between visits and are never uploaded to a server. The Save Manager on each game can export a save to a file as a backup.

How is WASM Arcade paid for?

By advertising. When you press Play, a sponsor page from one of our advertising partners opens in a new tab. You can close it; the game starts either way. The privacy policy names every partner.

Who owns these games?

Their original studios and publishers. WASM Arcade is not affiliated with any of them and claims no ownership of their games or trademarks. A rights holder who wants a game removed can send a takedown request as described on our copyright page, and we will remove it.

A game will not load. How do I report it?

First try an up-to-date Chrome, Edge or Firefox and close other heavy tabs. If it still fails, email [email protected] with the game, your browser and device, and what happened. The contact page lists everything that helps.
